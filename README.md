# Calias-finalact1-fluffyfish
A final requirement in B1-WMAD-309

Flappy Fish Game
Flappy Fish is a browser-based, side-scrolling arcade game inspired by Flappy Bird. The player controls a fish that swims upward when the screen is clicked. The objective is to navigate through moving pipes without colliding. The game is built with HTML5 Canvas, JavaScript, and styled with CSS. It includes background music, sound effects, and an offline detection feature.

🧩 Features
- Responsive game canvas (400x500px)
- Simple physics-based movement with gravity and lift
- Randomly generated pipe obstacles
- Score tracking with sound on each point
- Game over screen with replay functionality
- Background music and sound effects
- Offline detection banner

🚀 How to Play
- Open the game in a modern web browser.
- Click the "Start Game" button.
- Click anywhere on the screen to make the fish swim up.
- Avoid hitting the pipes or flying out of bounds.
- The game ends on collision or out-of-bounds.
- Click to restart after a game over.
